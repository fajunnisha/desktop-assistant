# 🖥️ Desktop Assistant

A Python desktop assistant built with **Tkinter** that allows users to open applications, access websites, and check the current date and time through a graphical interface.

## ✨ Features

- GUI with chat area and scrollbar
- Launch desktop applications
- Open websites through commands
- Display current date and time
- Enter key support
- Help and clear commands

## 🛠️ Technologies Used

- Python
- Tkinter
- OS module
- Webbrowser module
- Datetime module

## 🚀 How to Run

1. Install Python on Windows.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python assistant.py
```

## 💻 Available Commands

| Command | Function |
|---|---|
| `time` | Display current time |
| `date` | Display today's date |
| `open chrome` | Open Google Chrome |
| `open notepad` | Open Notepad |
| `open apex` | Open the GoalStriker website |
| `open spotify` | Open Spotify |
| `open word` | Open Microsoft Word |
| `open downloads` | Open Downloads folder |
| `open cursor` | Open Cursor |
| `open documents` | Open Documents folder |
| `open figma` | Open Figma |
| `open ccbp` | Open the CCBP learning portal |
| `open chat gpt` | Open ChatGPT |
| `open website github` | Open GitHub |
| `open website youtube` | Open YouTube |
| `help` | Display available commands |
| `clear` | Clear the chat area |

The `open website` command can also be used with other website names.

## ⚙️ Configuration

Some commands require installed applications or computer-specific paths.

| Command | What users should do |
|---|---|
| `open downloads` | Replace the Downloads path with their own. |
| `open documents` | Replace the Documents path with their own. |
| `open figma` | Set the path to their Figma executable. |
| `open chrome` | Ensure Chrome is installed. |
| `open spotify` | Ensure Spotify is installed. |
| `open word` | Ensure Microsoft Word is installed. |
| `open cursor` | Ensure Cursor is installed. |

Website access may require the user's own account and permissions.
